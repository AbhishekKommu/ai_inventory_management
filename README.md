# 🤖 SmartStock AI - Inventory Management System

A professional, AI-powered inventory management system built with Flask, featuring beautiful animated backgrounds and intelligent stock predictions.

## ✨ Features

- 🔐 **Secure Authentication** - Login/Register with password hashing
- 📦 **Full CRUD** - Complete product management
- 🤖 **AI Predictions** - Demand forecasting & reorder points
- 📊 **Real-time Dashboard** - Live analytics with charts
- 📜 **Activity History** - Complete audit trail
- 🎨 **Beautiful UI** - Animated gradient backgrounds
- 📱 **Responsive** - Works on all devices
- ⚡ **Fast** - Optimized queries & caching

## 🛠️ Tech Stack

- **Backend**: Flask 3.0, SQLAlchemy, Flask-Login
- **Frontend**: HTML5, CSS3, Vanilla JS, Chart.js
- **AI/ML**: NumPy, Pandas, Scikit-learn
- **Database**: SQLite (dev) / PostgreSQL (prod)
